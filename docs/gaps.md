# Gaps

> **Last updated:** 2026-11-26 · **Source:** `features.yaml` (updated 2026-11-26) and the engine's command list

Every known shortfall of Kition CAD, from the feature catalogue: features that are not yet `has`,
then the differences recorded on features that work. Update the feature in `features.yaml` when you
land work, then this list. The comparison with the target application is in
[parity/target-app-parity.md](parity/target-app-parity.md); the order of work is in [roadmap.md](roadmap.md).

## Differences on working features

- `cad.editor.ribbon`: The frame's order of giving way is the shared editor's (from the last group); a group's More is a panel, not a menu with keys of its own. Commands with the same meaning in different groups share an icon (Copy on Edit and Modify, Radius on Dimension and Parametric); the arc variants tell their points apart by small dots, crosses and arrows, which read best at the large size. A command whose title ends in "..." opens the shared parameter dialog, which puts every optional field under More options and takes points as [x, y] (Insert › Block... still does: web/tests/ribbon.mjs fills it); Hatch... and Drafting Settings... open the editor's own dialogs, and Home › Insert the Insert dialog (cad.editor.insert-block).
- `cad.editor.translation`: Command prompts and their options stay English ("Specify next point or [Close/Undo]"), by the owner's decision; option letters are typed as in English. Layer, style and block names are the drawing's own and are shown as they are.
- `cad.file.export`: Model space only (a layout prints with plot or exportpdf in the editor); the PNG is 2400 x 1600 whatever the drawing's shape; DWG is not an export, since the web build cannot write it.
