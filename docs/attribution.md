# Asset attribution

Every non-code asset in this repository (images, icons, fonts, example drawings, presets) is listed
here with its author, source and license. `cargo xtask assets` (part of `cargo xtask ci`) fails if
an asset file is missing from this table.

**Policy (mandatory):** Kition CAD contains **no Autodesk, Adobe or Avid iconography, images,
artwork, fonts, hatch patterns, linetypes, templates or presets.** Every asset is original work by
Kition contributors, upstream contributors (see NOTICE) or third-party material under an open license (OSI open source, public domain
/ CC0, or Creative Commons that allows redistribution). Screenshots of Autodesk software are never
committed. This repository has no font build input: the drafting font is generated in code (below),
and `kit.json` declares no bundled fonts for the editor.

Generated-in-code assets are original and have no file to list:
- the "Kition CAD Stroke" single-stroke drafting font (`crates/support/fonts/src/stroke.rs`);
- the standard linetype and hatch-pattern libraries (`crates/engine/doc/src/library.rs`; industry-common
  names, our own dash/spacing values);
- the colour index palette, generated from its structure (`crates/support/color/src/lib.rs`);
- the sample drawings (`crates/engine/engine/src/sample.rs`).
